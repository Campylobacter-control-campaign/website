# OpenMoji dashboard icons

The SVG files in this directory are from **OpenMoji**, an open-source emoji project by HfG Schwäbisch Gmünd and contributors.

Source: https://openmoji.org/  
Upstream repository: https://github.com/hfg-gmuend/openmoji  
License: **CC BY-SA 4.0** — https://creativecommons.org/licenses/by-sa/4.0/

The files are vendored here so the CCC dashboard does not depend on OpenMoji's web server at runtime.

Included codepoints:

- 1F46A — family
- 1F3E0 — house
- 1F414 — chicken
- 1F410 — goat
- 1F404 — cow
- 1F333 — deciduous tree
- 1F4A7 — droplet
- 1F465 — busts in silhouette
- 1F9EA — test tube
- 1F9EB — petri dish
- 1F476 — baby
- 1F4CA — bar chart
- 1F9D1 — person
- 1F43E — paw prints
- 1F33F — herb
- 1F411 — sheep
- 1F416 — pig
- 1FACF — donkey

No visual modifications have been made to the upstream SVG artwork.
